- POST /api/auth/central-set-password: the single-use invitation token is the principal
- POST /api/auth/forgot-password: asks for a reset email; answers the same whether or not the account exists
- POST /api/auth/reset-password: the single-use reset token is the principal
- POST /api/ess/activate: the single-use activation token is the principal
- POST /api/ess/auth: ESS sign-in: the credentials are the principal
